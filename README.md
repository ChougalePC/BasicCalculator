# 🧮 Simple Calculator

My first JavaScript project built while learning web development.

This calculator performs basic arithmetic operations and updates the result dynamically on the page.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🚫 Division-by-zero handling
- 🎯 Simple and beginner-friendly interface

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## What I Learned

While building this project, I practiced:

- Working with the DOM
- Using document.getElementById()
- Handling button clicks
- Creating and calling functions
- Reading user input
- Updating content dynamically with JavaScript
- Basic debugging and problem solving
